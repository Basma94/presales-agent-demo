# Presales Agent (Demo)

A single-file, client-side prototype of a Vodafone-style Presales Agent tool.

- **Client-side only** — no backend, no server, no API calls.
- **Mock data** — all data shown is simulated for demo purposes.
- Everything (markup, styles, and logic) lives in `index.html`.

## Running locally

Just open `index.html` in a browser, or serve the folder with any static file server.

## Live demo

Served via GitHub Pages from the `main` branch root.
